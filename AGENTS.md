# Работа над ИЗОБАРОЙ

Развивать существующую одиночную 3D action-RPG локальными изменениями.

- Перед работой прочитать `README.md` и `docs/ARCHITECTURE.md`; для работы по roadmap — выбранный пакет `roadmap.md`.
- Сохранять 3D-мир, текущий движок, художественное оформление, подключённые изображения, совместимость сохранений и автономный запуск.
- Общая просьба «работать по roadmap/README» не разрешает смену движка, переписывание игры с нуля, переход к 2D, удаление ассетов или замену существующей графики примитивами, заглушками либо CSS-рисунками. Такие изменения допустимы только по отдельному явному поручению владельца. Программные 3D-модели являются действующим оформлением игры.
- `ASSETS.md` описывает текущий каталог. `docs/asset-production/`, `evidence/asset-audit/` и результаты в `output/assets/` — архив завершённого производства и свидетельства происхождения, а не очередь работ. Исторические замечания не являются дефектами текущих файлов.
- Для изменений кода выполнять подходящие проверки из README и выбранного пакета; указывать фактически выполненные проверки и ограничения. Для правок только документации проверять ссылки, согласованность и diff; пересборка игры не требуется.
