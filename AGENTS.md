# Работа над ИЗОБАРОЙ

1. Перед любыми правками прочитать [границы изменений](docs/CODING_STANDARDS.md#scope).
2. Для изменений кода, игрового поведения или сборки прочитать [контекст игры](docs/CODING_STANDARDS.md#code-context); для правок только документации — [контекст документов](docs/CODING_STANDARDS.md#docs-context).
3. Перед изменением ассетов или описанием их состояния и истории прочитать [правила каталога и архива](docs/CODING_STANDARDS.md#assets).
4. Перед завершением выполнить [проверки для своего типа изменений](docs/CODING_STANDARDS.md#verification) и указать полученные результаты и ограничения.
