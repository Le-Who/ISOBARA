# Что хранится в evidence

В Git остаются компактные отчёты Markdown/JSON, скрипты проверок Python и архив `asset-audit/` целиком: его изображения служат свидетельствами происхождения и приёмки игровых ассетов. Результаты кампании, браузерных проверок и матрицы баланса позволяют проверить основания решений, но не заменяют пользовательский плейтест.

Скриншоты обычных прогонов, видео, трассировки, сырые консольные логи и текстовые дампы остаются локальными и игнорируются. Тестовые сохранения `fixtures/`, `browser-export.json` и `state.json` также не публикуются. Файлы не удаляются с диска при снятии с отслеживания Git; старые коммиты сохраняют прежние версии.

Новый набор свидетельств помещайте в отдельный каталог с компактным отчётом: версия игры, окружение, команда/метод, результат, ограничения. Не добавляйте секреты, адреса личных сервисов или пользовательские сохранения. Если нужны новые постоянные типы файлов, согласованно измените `.gitignore` и фильтр `keep_evidence` в `tools/package_release.py`.

Релизный ZIP использует ту же политику отбора свидетельств. Обычная сборка игры не зависит от содержимого `evidence`.
