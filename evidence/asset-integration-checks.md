# Проверка интеграции ассетов — 2026-09-28

Восемь исправленных WebP установлены в `public/assets` под прежними именами. Проверка до копирования подтвердила для каждого файла уникальный SHA-256, RGBA с альфой 0–255, размер не более 384×384 и непустой прозрачный запас по четырём сторонам при пороге alpha ≥ 16. После копирования SHA-256 назначения совпал с кандидатом. Актуальные размеры и хеши записаны в `evidence/asset-manifest.json`.
