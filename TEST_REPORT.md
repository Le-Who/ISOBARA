## Браузерный интерфейс и рендер

Историческая целевая проверка переходов: **успешно**. Через Playwright CLI выполнено 20 циклов входа в разлом и отступления через игровые интерфейсы. Ошибок JavaScript и WebGL в консоли не было; число геометрий рендерера после прогрева менялось от 43 до 48, текстур — 5. Результат сохранён в `evidence/browser-tests.json`; это отдельный прогон до новой интеграции ассетов.

Это точечная проверка регрессии переходов, а не полный прогон `tests/browser_test.py`. Ранее этот полный прогон не смог открыть локальный адрес из-за ограничения среды `ERR_BLOCKED_BY_ADMINISTRATOR`. В новой попытке после замены иконок причина другая: отсутствует Python-модуль `playwright`; подробности ниже. Исторические и текущие причины не следует объединять в один результат.

Экран награды, переполненная сумка и часть переходов проверяются с явно импортированными тестовыми сохранениями. Скриншоты этих экранов не являются доказательством прохождения соответствующего боя. Браузерный тест не заявляет полное прохождение кампании за человека.

## Обновление 2026-09-28: иконки и производительность

Восемь иконок с дефектами вырезки заменены отдельными изображениями с альфа-прозрачностью. Подробности, размеры и проверки — в [отчёте интеграции](evidence/asset-integration-checks.md), происхождение — в [ASSETS.md](ASSETS.md), `output/assets/equipment-repair/` и `output/assets/repair-candidates/`. По отчёту после интеграции прошли `npm run check`, `npm test` (12/12), `npm run build` и браузерная проверка запуска мира/инвентаря через Playwright CLI. Полный `npm run test:browser` недоступен: в локальном Python отсутствует модуль `playwright`.

Целевой браузерный сценарий того периода проверил создание мира seed `19320422` и инвентарь: 8 из 8 DOM-изображений этого экрана загружены, сломанных нет. Это не проверка всех экранов, не полный набор из `tests/browser_test.py` и не прохождение кампании. На тот момент в игровом каталоге было 12 изображений; текущий состав указан в верхней таблице.

Лаборатория производительности сохранила пять исходных прогонов в `evidence/performance-lab/baseline-runs.json`; медиана времени основного потока 2,00 мс для зафиксированного сценария Chrome/Intel Iris Xe/1280×720. Проверенных патчей нет. Условие совокупного ускорения не менее 10% и трёх последних вариантов с приростом менее 1% не выполнено; процент улучшения не заявляется. Статус и причины остановки — в `evidence/performance-lab/continuation-status.md`.

Значение 2,00 мс — медиана пяти медиан CPU-метрики `mainThreadMs` в короткой сцене первого разлома, а не полное время кадра. Замеры не подтверждают производительность во всей кампании и не заменяют новый baseline при изменении сборки или сценария.
